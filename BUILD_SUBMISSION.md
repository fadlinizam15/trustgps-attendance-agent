# Submission Guide — Terminal 3 Build+Scale Agent Micro Grant

## 1. Create a Git Repository & Push This Code
1. Create a new repository on **GitHub**, **GitLab**, or **Bitbucket**.
2. Extract this archive and push the files to your repository:
   ```bash
   git init
   git add .
   git commit -m "feat: add GPS barcode attendance system and build documentation"
   git branch -M main
   git remote add origin <YOUR_GIT_REPO_URL>
   git push -u origin main
   ```
